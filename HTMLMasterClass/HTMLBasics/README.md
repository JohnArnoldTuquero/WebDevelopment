# 🌐 HTML Basics

Learn the fundamentals of HTML and understand how every webpage is built.

This lesson introduces the basic concepts of HTML, the structure of an HTML document, and the essential tags used to create web pages. By the end of this lesson, you will be able to build your very first webpage from scratch.

---

# 🎯 Objectives

After completing this lesson, you should be able to:

- Understand what HTML is.
- Explain the role of HTML in web development.
- Create a basic HTML document.
- Use common HTML tags correctly.
- Build a simple webpage.
- Run HTML files using VS Code and Live Server.

# 💻 Lessons

## 01 - Hello HTML

Learn how to create your first HTML file.

Topics

- Creating an HTML file
- Opening it in a browser
- Writing your first HTML code

Practice

- Display "Hello, World!"
- Change the page title
- Experiment with different text

---

## 02 - HTML Structure

Learn the standard structure of every HTML document.

Topics

- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<title>`
- `<body>`

Practice

- Build a complete HTML document from scratch.
- Add a page title.
- Display content inside the body.

---

## 03 - Headings

Learn how to organize content using headings.

Topics

- `<h1>` to `<h6>`

Practice

- Display all heading levels.
- Create a webpage with a proper heading hierarchy.

---

## 04 - Paragraphs

Learn how to display blocks of text.

Topics

- `<p>`

Practice

- Create multiple paragraphs.
- Write a short introduction about yourself.
- Build a simple article.

---

## 05 - Comments

Learn how comments work.

Topics

- `<!-- Comment -->`

Practice

- Add comments explaining different parts of your code.
- Hide content using comments.

---

## 06 - Line Breaks

Learn how to insert line breaks.

Topics

- `<br>`

Practice

- Display a poem.
- Display an address.
- Format song lyrics.

---

## 07 - Horizontal Rule

Learn how to separate sections.

Topics

- `<hr>`

Practice

- Separate webpage sections.
- Create a simple article using headings, paragraphs, and horizontal rules.
