# 🎨 CSS Introduction

Learn the fundamentals of CSS and discover how websites become beautiful, organized, and responsive.

This lesson introduces Cascading Style Sheets (CSS), the language used to style HTML documents. By the end of this lesson, you will understand how CSS works, how to connect it to HTML, and how to write your first styles.

---

- Understand what CSS is.
- Explain the purpose of CSS.
- Differentiate HTML and CSS.
- Apply CSS using different methods.

# ⚖️ Inline vs Internal vs External CSS

| Method | Description | Best Used For |
|----------|-------------|---------------|
| Inline | CSS inside an HTML tag | Small testing |
| Internal | CSS inside `<style>` | Single webpage |
| External | Separate `.css` file | Real websites |

# 💡 Best Practices

- Always use External CSS whenever possible.
- Keep CSS readable.
- Indent your code properly.
- Use meaningful comments.
- Group related styles together.
- Avoid repeating the same styles.
- Write clean and organized code.

---

# ❌ Common Beginner Mistakes

- Forgetting the semicolon (`;`)
- Misspelling property names
- Forgetting curly braces (`{}`)
- Incorrect file linking
- Mixing HTML and CSS unnecessarily
- Using too much Inline CSS
